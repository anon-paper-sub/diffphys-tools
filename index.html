Learned Differentiable Physics for Planning with and Designing Deformable-Manipulation Tools

Anonymous Authors

We learn a dynamics model for deformable object manipulation directly from real robot RGB-D data. A single graph neural network is trained on nine tools spanning three interaction modes (grippers, rollers, and presses), using the real-robot dataset from RoboCook. Its feature parameterization is rotation- and particle-density-invariant by construction, which lets it generalize to new tools and new manipulation trajectories. Because the model is differentiable, it can also design a tool, or plan the motion of up to four grippers, to reach a target dough shape.

Zero-shot generalization to new tool geometries

Tool configurations absent from the training data. The model was trained with two plate grippers and is rolled out with three (at 120°) and four (at 90°), which press the dough into the polygon they bound. A ring press and a knife are entirely new shapes. These tools were never recorded on the robot, so there is no ground truth and the rollouts can only be judged qualitatively.
